# LedApp

Installers for LedApp, an app that controls your PC's RGB lighting, fans, pump and cooler screen.

**Download:** open [Releases](https://github.com/MiguelSantosL/LedApp-releases/releases/latest) and download `LedApp-Setup-<version>.exe`.

Already have LedApp 1.0.2 or later? It updates itself: click **Update now** when it tells you a new version is ready.

This repository only holds the installers. LedApp's source code is not published here.
